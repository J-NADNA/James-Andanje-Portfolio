# James Andanje Portfolio v2

Professional portfolio for Okello James Andanje — Executive Assistant, Business & Research Support.

## Stack

- HTML5
- Modern CSS
- Vanilla JavaScript
- Netlify-ready (no build step)

## Files

- `index.html` — content and structure
- `style.css` — white, royal-blue and gold design
- `script.js` — navigation, animation, counters, filtering, modals, clipboard interactions and motion effects
- `assets/favicon.svg` — site icon
- `netlify.toml` — simple Netlify configuration and security headers

## Deploy

This version is intentionally build-free. Upload the files to the root of the GitHub repository and Netlify can publish them directly.

If replacing an older version, remove or ignore the old `style.css` and `script.js` files so the repository stays clean. This version uses `style.css` and `script.js`.
